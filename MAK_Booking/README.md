# M.A.K Booking — v1.5

تطبيق Flutter متكامل لحجز خدمات التصميم، بواجهة عربية RTL وإنجليزية، وثيم M.A.K الداكن. يحتوي المشروع على منصتي Android وiOS، وربط Supabase، وتخزين محلي وOutbox للعمل دون إنترنت.

## التشغيل السريع في وضع Demo

يتطلب Flutter 3.24 أو أحدث وDart 3.5 أو أحدث:

```bash
flutter pub get
flutter run --dart-define=DEMO_MODE=true
```

لا يحتاج وضع Demo إلى إعداد قاعدة البيانات. سجّل الدخول بأي بريد صحيح وكلمة مرور من 6 أحرف؛ الحساب التجريبي يملك دور المدير لتجربة كل الشاشات.

## التشغيل الحقيقي مع Supabase

بيانات مشروع Supabase الموجودة في `lib/core/config/app_config.dart` مضبوطة بالفعل.

1. افتح مشروع Supabase ثم SQL Editor.
2. نفّذ كامل الملف `supabase/schema.sql` مرة واحدة قبل تسجيل أول مستخدم.
3. شغّل التطبيق:

```bash
flutter pub get
flutter run
```

أول حساب يُنشأ يصبح مديراً تلقائياً، والحسابات التالية عملاء. لإطلاق تجريبي سريع يمكن تعطيل Confirm email من إعدادات Supabase Auth؛ أما في الإنتاج فيُنصح بتفعيل تأكيد البريد.

## ما هو منفذ

- تسجيل الدخول وإنشاء الحساب وحماية صفحة المدير حسب الدور.
- الصفحة الرئيسية بأقسام التصميم والويب والكتابة، وصفحتا «قريباً» للقسمين الأخيرين.
- معالج تصميم من 6 خطوات: 75 خدمة بفئات 300 و700 و1800 د.م.، و68 موك أب، و19 أسلوباً بينها Graphity.
- اختيار 3–5 ألوان، وبريف من 30 سؤالاً على ثلاث دفعات، ومراجعة نهائية بالإجمالي والعربون 10٪ والمتبقي.
- قائمة طلبات حية، تفاصيل الطلب، شريط الحالة، رمز تحقق قابل للنسخ، ولوحة مؤشرات للمدير.
- محادثة Realtime، وعقد عربي/إنجليزي، وتوقيع إلكتروني ورفع التوقيع إلى تخزين خاص.
- قاعدة SQLite محلية للطلبات والرسائل، وOutbox يعيد إرسال العمليات المعلقة عند عودة الاتصال.
- ترجمة بشرية كاملة في `assets/translations/ar.json` و`assets/translations/en.json` مع حفظ اللغة المختارة.
- أيقونة M.A.K مضبوطة لنظامي Android وiOS.

## الاختبارات والبناء

```bash
flutter analyze
flutter test
flutter build apk --release
flutter build ios --release
```

بناء iOS يتطلب macOS وXcode. توقيع حزم الإصدار وشهادات المتاجر يُضبطان على جهاز المطور قبل النشر.

## ملاحظات

- `supabase/schema.sql` يتضمن الجداول والفهارس وسياسات RLS وRealtime ومسارَي التخزين الخاصين ودوال الإرسال والتوقيع.
- يمكن استبدال العلامة المرسومة داخل التطبيق بالشعارات النهائية في `assets/logos/` عند توفرها.
- لا تضف مفتاح `service_role` أو كلمة مرور PostgreSQL إلى التطبيق؛ المفتاح العام الحالي هو المقصود للعميل مع سياسات RLS.
