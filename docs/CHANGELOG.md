# سجل التغييرات

## 2.0.0
**إصلاحات**
- العملاء الجدد يدخلون بشكل صحيح (دور `client` تلقائياً؛ أول مستخدم فقط مدير) — اختبار في `supabase/tests/rls_tests.sql`.
- الموظف يرى كل الطلبات بكامل بياناتها: اسم الطلب، العميل، الخدمات، الألوان، الـ Mockups، والأسئلة الثلاثين.
- تطبيق واحد بثلاث طبقات: **المدير** (الأعلى، يرى ويتحكم بكل شيء ويستطيع التبديل لعرض الموظف/العميل) ← **الموظف** (كل طلبات العملاء، تسعير، عقد، دفعات) ← **العميل** (طلباته فقط).

**ميزات**
- الألوان يكتبها العميل (3 إلى 5) بصيغة HEX أو RGB أو CMYK مع تحقق ومعاينة.
- اختيار Mockups بشبكة صور (حتى 5) ومكان واضح لوضع الصور.
- معالج كامل للتصميم والويب والكتابة، مع حفظ مسودة تلقائي واستكمال بعد الانقطاع.
- استقبال طلب غني: 30 سؤالاً + ملفات + اسم طلب تلقائي.
- الأسعار 150 / 350 / 700 / 950 د.م.، تُعدَّل من المدير أو موظف له صلاحية؛ البنود غير المعتمدة = تسعير يدوي.
- الموظف يعدّل السعر والعقد؛ الفرق المتغيّر في السعر يحتاج اعتماد المدير.
- عقد 15 مادة بالعربية والإنجليزية + ملاحق + توقيع بخط اليد + PDF.
- تعديل/إلغاء بنافذة 3 أيام مجانية ثم رسوم، والإلغاء بالتحقق من رمز الطلب.
- معاينات بعلامة مائية، ونسخة نهائية بعد الدفع.
- تقييم الفريق (العميل 1–5، المدير 1–10) ولوحة صدارة.
- محاسبة: دخل مؤكَّد، مصروفات، رواتب، صافي شهري، تصدير CSV.
- بناء تلقائي على GitHub: APK، EXE، MSI، ويب (PWA لـ iOS/macOS).

## تحديث الطبقة البصرية
- لوحة ألوان العميل مأخوذة من luxury-client-command-center (#0A0B0D / تركوازي #2DD4BF / ذهبي #F4B942).
- خط Sora للعناوين والأرقام (Cairo للعربية).
- ظلال عميقة، توهج تركوازي/ذهبي في الخلفية، بطاقة ترحيب بتدرج، أزرار بتوهج، رفع البطاقات عند المرور، انتقال متحرك بين الصفحات.
